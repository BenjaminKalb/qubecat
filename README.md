# Qubecat 3D Voxel Engine written on Rust
- Currently in early-development.

## Quick Start
> [!TIP]
> Requires Rust 1.85+ (the project uses edition 2024). Get it from [rust-lang.org](https://rust-lang.org/).
``` bash
git clone https://github.com/qubecat-studios/qubecat-engine.git
cd qubecat
cargo build
cargo run
```
